# SkyTrip — Proyecto final

Sitio responsive en español desarrollado con HTML5, CSS y JavaScript, inspirado en el documento académico de SkyTrip.

## Ver el proyecto
Abrir `index.html` o servir esta carpeta con un servidor estático. No requiere instalación ni compilación.

## Contenido
Encabezado y navegación, hero, tres tarjetas, presentación del proyecto, galería de seis imágenes con ampliación, video HTML5, audio local original, formulario con validación HTML5 y pie de página. Incluye diseño móvil, navegación por teclado y respeto por movimiento reducido.

## Límites de la demostración
El formulario valida pero no envía ni almacena datos. Las redes enlazan a las plataformas, sin cuentas oficiales de SkyTrip. No hay reservas, precios en vivo, cuentas ni integración con IA. La tipografía y el video requieren conexión; las fotos y el audio están incluidos localmente.

## Créditos
IA (Codex). Concepto SkyTrip basado en el material proporcionado por el usuario. Fotografías: Unsplash (IDs originales en assets/SOURCES.md). Video: Big Buck Bunny, Blender Foundation, CC BY 3.0. Música: melodía original generada para el proyecto.

## Hosting
GitHub Pages sirve la rama main desde la raíz. Los cambios publicados en main actualizan el sitio.
